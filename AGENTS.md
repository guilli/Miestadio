# Reglas del repo

- **main es la rama de producción.** No hagas NADA en main (commits, merges, pushes, rebases, resets) salvo que el usuario lo pida explícitamente. Todo el trabajo va en ramas de feature/fix y se consolida cuando el usuario lo indique.
- Convención de mensajes de commit: prefijos en español estilo conventional commits (p. ej. `feat(ui):`, `fix(android):`, `chore:`).
